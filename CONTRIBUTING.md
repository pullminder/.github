# Contributing to Pullminder

Thank you for your interest in contributing to Pullminder.

## Repository guide
[pullminder](https://github.com/pullminder) Distribution: npm, Homebrew, GitHub Action, and org-level community health files. 

The repositories in this organization are distribution channels — they wrap and ship releases built from the monorepo.

## How to contribute

### Registry packs

The [official rule pack registry](https://github.com/pullminder/registry) accepts community pack submissions:

1. Read the [pack authoring guide](https://docs.pullminder.com/packs/authoring-guide).
2. Submit your pack as a pull request to [pullminder/registry](https://github.com/pullminder/registry).
3. Include a `pack.yaml` and `pack.schema.json` that pass AJV validation.

### Documentation

Documentation lives at [docs.pullminder.com](https://docs.pullminder.com). To suggest improvements, open an issue in [pullminder/registry](https://github.com/pullminder/registry/issues) with the `documentation` label.

## Code of Conduct

This project follows the [Contributor Covenant Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.
